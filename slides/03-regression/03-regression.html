—- Regression Basics

Multiple Linear Regression

Time series regression models postulate a linear relationship between the average level of a response (output) varaible \(y_t\) and a bunch (say \(p\)) of predictor (input) variables \(\textbf{x}_t = (x_{t,1}, \ldots, x_{t,p})\) for each time point \(t\).

\[y_t = \beta_0 + \beta_1 x_{t,1} + \beta_2 x_{t,2} + \cdots + \beta_k x_{t,p} + \epsilon_t\] Simplest case is ‘simple linear regression’ with \(p = 1\). The input variables could be simple functions of time e.g. \(x_{t,1} = t\) for fitting a ‘Linear Trend’ or \(x_{t,1} = t, x_{t,2} = t^2\) for fitting a ‘Quadratic Trend’ or \(x_{t,1} = A\cos(\theta t + \eta)\) for a periodic mean or \(x_t\) could simply be other contemporaneous time series or lags of contemporaneous time series.

Errors in the equation

Key assumption about the ‘error’ \(\epsilon_t,\, t = 1, \ldots, T.\)

  • Errors have mean zero; otherwise the fit/forecasts will be systematically biased.
  • Errors are not autocorrelated; otherwise the forecasts will be inefficient, as there is more information in the data that can be exploited.
  • Errors are unrelated to the predictor variables; otherwise there would be more information that should be included in the systematic part of the model. More generally, the input variables have to be ‘exogenous’, i.e. \(E(\epsilon_t | x_t) = 0.\) This along with mean zero errors will mean that the imput variable is uncorrelated with the error term

SOI and Rec CCF

  • In time series regression we have the opportunity to add the lagged values of the predictors as possible predictors.
  • The sample cross-correlation and CCF function are defined as

\[ \widehat{\gamma}_{xy}(h) = \frac{1}{n}\sum_{i=1}^{n-h}(x_{t+h} - \bar{x})(y_t - \bar{y}) \]

\[ \widehat{\rho}_{xy}(h) = \frac{\widehat{\gamma}_{xy}(h)}{\sqrt{\widehat{\gamma}_x(0)\widehat{\gamma}_y(0)}} \]

SOI and Rec CCF

  • The sample CCF in Figure 4 ACf shows some departure from the cyclic component of each series and there is an obvious peak at \(h = −6\).
  • This result implies that SOI measured at time \(t − 6\) months is associated with the Recruitment series at time \(t\).
ccf(soi, rec, 48, main="SOI vs Recruitment", ylab="CCF")

Lagged regression for SOI on Rec

Consider the following lagged regression, \[R_t = \beta_0 + \beta_1 S_{t-6} + w_t\] where \(R_t\) denotes Recruitment for month \(t\) and \(S_{t-6}\) denotes SOI six months prior. Assuming the \(w_t\) sequence is white, the fitted model is \[\hat{R}_t = 65.79 - 44.28_{(2.78)}S_{t-6}\]

The slope estimate is statistically significant (standard error is given in parenthesis)

—- Useful Predictor variables

Trend

A linear trend can be modelled by simply using \[x_{1,t} = t\] as a predictor,

\[y_t = \beta_0 + \beta_1 t + \epsilon_t\]

Dummy variables

  • A dummy variable is also known as an “indicator variable”.

  • Example a predictor is a categorical variable taking only two values (e.g., “yes” and “no”)?

    • when forecasting daily sales and you want to take account of whether the day is a public holiday or not.
    • So the predictor takes value “yes” on a public holiday, and “no” otherwise.

  • a “dummy variable” which takes value 1 corresponding to “yes” and 0 corresponding to “no”.

  • A dummy variable can also be used to account for an outlier in the data.

  • Rather than omit the outlier, a dummy variable removes its effect.

  • In this case, the dummy variable takes value 1 for that observation and 0 everywhere else.

  • We can model this data using a regression model with a linear trend and quarterly dummy variables,

\[y_t = \beta_0 + \beta_1 t + \beta_2 d_{2,t} + \beta_3 d_{3,t} + \beta_4 d_{4,t} + \epsilon_t,\]

  • \(d_{i,t} = 1\) if \(t\) is in quarter \(i\) and 0 otherwise.
  • The first quarter variable has been omitted, so the coefficients associated with the other quarters are measures of the difference between those quarters and the first quarter.

Intervention variables

  • Often necessary to model interventions that may have affected the variable to be forecast.
    • For example, competitor activity, advertising expenditure, industrial action

Trading Day

  • \(x_1\) = number of Mondays in month;
  • \(x_2\) = number of Tuesdays in month;
  • \(\vdots\)
  • \(x_7\) = number of Sundays in month.

Distributed lags

  • Often useful to include advertising expenditure as a predictor.

  • The effect of advertising can last beyond the actual campaign

  • Need to include lagged values of advertising expenditure

  • \(x_1\) = advertising for previous month;

  • \(x_2\) = advertising for two months previously;

  • \(\vdots\)

  • \(x_m\) = advertising for \(m\) months previously.

Holiday

Some holidays can move around in the calendar

  • Easter
  • Chinese New Year
  • Ramadan

Fourier series

  • Alternative to using seasonal dummy variables
  • Useful for long seasonal periods

If \(m\) is the seasonal period, then the first few Fourier terms are given by:

  • \(x_{1,t} = \sin \left( \frac{2 \pi t}{m} \right)\)
  • \(x_{2,t} = \cos \left( \frac{2 \pi t}{m} \right)\)
  • \(x_{3,t} = \sin \left( \frac{4 \pi t}{m} \right)\)
  • \(x_{4,t} = \cos \left( \frac{4 \pi t}{m} \right)\)
  • \(x_{5,t} = \sin \left( \frac{6 \pi t}{m} \right)\)
  • \(x_{6,t} = \cos \left( \frac{6 \pi t}{m} \right)\)

Need for nonlinear regression

The relationship is nonlinear and different when SOI is positive or negative. In this case, we may consider adding a dummy variable to account for this change. In particular, we fit the model: \[ R_t = \beta_0 + \beta_1 S_{t-6} + \beta_2 D_{t-6} + \beta_3 D_{t-6} S_{t-6} + w_t \] where \(D_t\) is a dummy variable that is 0 if \(S_t < 0\) and 1 otherwise. This means that: \[ R_t = \begin{cases} \beta_0 + \beta_1 S_{t-6} + w_t & \text{if } S_{t-6} < 0, \\ (\beta_0+\beta_2) + (\beta_1+\beta_3)S_{t-6} + w_t & \text{if } S_{t-6} \geq 0. \end{cases}\]

Nonlinear Models

More generally the relationship between the input and out time series could be any nonlinear function, parametric as well as non-parametric and the input can include the current value and/or lagged valued of the input series.

\[ y_t = g(x_t, x_{t-1}, \ldots, x_{t-H}, \theta) + \epsilon_t \]

or

\[ y_t = g(x_t, x_{t-1}, \ldots, x_{t-H}) + \epsilon_t \]

The errors are usually taken to be additive (adding to the systematic part). The function \(g\) could be any function but usually some features are important, e.g. smooth function or piecewise smooth and simple function.
